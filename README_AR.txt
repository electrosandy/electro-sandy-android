ELECTRO Sandy V30 — تطبيق Android لإدارة المحل

المزايا:
- المنتجات والمخزون والتحويلات والتنبيهات والضمان.
- المبيعات والفواتير والمرتجعات والأداء النقدي والبنكي والمختلط والديون.
- المشتريات والموردون والأداء الجزئي.
- الزبناء ونقاط الوفاء والتقارير والتصدير.
- نسخ احتياطي محلي واستعادة محمية بنسخة أمان.
- مزامنة Firebase اختيارية مع كشف تعارضات التعديل.
- حماية PIN محلية ودعم البصمة عند توفرها.

البناء:
- افتح المشروع من جذر المستودع في Android Studio باستخدام JDK 17.
- يمكن بناء نسخة Debug بالأمر: gradle assembleDebug
- APK الناتج: app/build/outputs/apk/debug/app-debug.apk

تنبيهات:
- معرّف التطبيق الحالي com.electrosandy.app.fresh لتثبيته بجانب النسخة السابقة دون استبدال بياناتها.
- نسخة Debug للتجربة وليست نسخة Release للنشر في Google Play.
- قواعد Firestore يجب مراجعتها ونشرها يدوياً في Firebase Console.
- المزامنة السحابية تعتمد النسخ الكاملة وكشف التعارضات، وليست دمجاً تلقائياً لكل سجل. يجب اختبار هاتفين حقيقيين قبل الاعتماد عليها.
- احتفظ دائماً بنسخة احتياطية قبل الاستعادة أو حذف بيانات التطبيق.
